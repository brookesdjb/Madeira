## Additional PR37 state-reset finding

At the reviewed head, `mad_ei_apply()` writes root constants/descriptors and
vertex/index bindings into the persistent `mad_exec`. The indirect-command loop
in `madeira_d3d12.c` (around lines 4822–4829) exits without clearing those affected
bindings. A following command can therefore inherit the last indirect record's
state. [Microsoft's indirect-drawing contract](https://learn.microsoft.com/en-us/windows/win32/direct3d12/indirect-drawing#command-signatures)
requires the signature's affected vertex/index buffers and root views to become
null and affected root constants to become zero after ExecuteIndirect. This is
a source-review finding, not a reproduced iPad failure. Add a post-indirect
ordinary draw/dispatch regression (including a zero-count case), implement the
required reset, and still run the existing guest cases before acceptance.
